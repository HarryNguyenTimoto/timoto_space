## Summary

Base: `https://internal.timoto.ai/api` (prod `https://prod-internal.timoto.ai/api`). Mount: `backend/config/urls.py` → `bikes/api_urls.py`. Default: OPS JWT. Swagger: `/api/docs/`. Schema JSON: `/api/schema/`.

## Auth / staff

| Method | Path | Auth |
| --- | --- | --- |
| POST | `/auth/login/` | Public `{phone, password}` |
| POST | `/auth/refresh/` | Public `{refresh_token}` |
| POST | `/auth/logout/` | Public |
| GET | `/auth/me/` | JWT |
| POST | `/auth/register-fcm-token/` | JWT |
| GET/POST | `/admin/staff/` | JWT\+ADMIN |
| PATCH | `/admin/staff/{user_id}/` | JWT\+ADMIN |
| POST | `/admin/staff/{user_id}/reset-password/` | JWT\+ADMIN |

## Contract (submit)

`offer_to_user` = FMP. `resale_price` ≤ FMP. Server sets `listing_price_vnd` and `instant_price_vnd`. See [Sell → pickup](/flows/sell-to-pickup).
