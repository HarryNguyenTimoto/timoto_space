## Dealer — live FE vs collection

Collection is auctions \+ VietQR \+ notifications. Hub v2 actually calls:

- `GET /catalog/bikes/` `GET /catalog/bikes/:comboId/`
- `GET /bikes/:id/ai-report/` (read-only `BikeEvaluationResult`)
- `POST /orders/` then `POST /payments/dealer-order/create/` (not CONTRACT `POST /orders/{id}/pay/`)
- `GET /orders/:id` poll paid
- Checkout draft: `POST /api/v1/payments/checkouts/` dual-issuer JWT (`SHARED_CHECKOUT_CONTRACT.md`)
- HMAC `POST` mobile `/internal/inventory/bike-sold/` and `/internal/payments/checkout-paid/`

## How to keep this page honest

After adding a Django route: add a Postman folder **or** a row here in the same PR. Agents must grep `urls.py` vs this table, not assume Postman is complete.
