## Summary

Base: `https://api-staging.timoto.ai/api/v1` (prod `https://api.timoto.ai/api/v1`). Source: `backend/apps/*/urls.py`. Default DRF: Cognito \+ IsAuthenticated unless noted.

## Bikes / evaluate

| Method | Path | Auth |
| --- | --- | --- |
| CRUD | `/bikes/` ViewSet | AllowAny \+ device/owner checks |
| POST | `/bikes/{id}/evaluate/` | AllowAny — **production gRPC path** |
| POST | `/bikes/{id}/evaluate/async/` | AllowAny |
| GET | `/bikes/{id}/evaluate/result/` | AllowAny |
| POST | `/bikes/{id}/media/` and `/media/batch/` | AllowAny |

Contract: `data.output_jsons` length **3**, `error_message` empty. See workspace evaluate rule.

## Auth / Zalo / OCR / upload

See [Zalo login](/features/zalo-login) and [Cavet OCR](/features/cavet-ocr). Upload prefix `/upload/` all AllowAny. Options prefix `/options/` public catalogs.

## S2S inbound

`POST /internal/listings/{listing_id}/buyer-found/` HMAC. **If secret env empty, verifier returns True — misconfig is unsigned.**

## Not in urls.py (do not call)

`/marketplace/purchase-orders/*`, `/marketplace/payments/*` — app-only WIP.
