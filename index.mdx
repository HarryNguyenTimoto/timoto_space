Private technical KB for TiMoto. Humans and agents (Cursor, Claude Code, Autonoma) read this instead of grepping six repos.

## Summary

This site is **Private**. Specs are not public. If you can read a page without Mintlify login, treat that as an incident.

Wave 1 (this sprint) covers the three journeys Autonoma and CI need first:

- [Zalo login](/features/zalo-login) — iOS native SDK vs Android/WebView, VN Graph IP
- [Cavet OCR](/features/cavet-ocr) — camera → Gemini → Step01 form. Real device only for E2E
- [Sell → OPS → pickup](/flows/sell-to-pickup) — FMP in, TIPP/listing out, HMAC offer, pickup
