## Summary

**timoto-mobile** is the rider product: React Native `Apps/` (not legacy `TiMotoAI/`) \+ Django `backend/` on `api.timoto.ai`. Default DRF auth is Cognito JWT, but many bike/upload/OCR/evaluate routes are still **AllowAny** with device\_id checks.

## Repos / files

- App: `Apps/src/` — API `Apps/src/api/endpoints.ts`
- Django urls: `backend/config/urls.py` \+ `backend/apps/*/urls.py`
- Postman (101 requests): `backend/postman/Timoto_API.postman_collection.json`
- Local tests: `python manage.py test --settings=config.settings_test`
- Test runner: `./backend/test-runner.sh backend-unit` (or target: `mkt-filters`, `buy-flow`, `prod-api`, `staging-api`, `realtime-ws`, `eval-flow`)

## Frontend ↔ backend

App uses REST to `API_BASE` (`https://api-staging.timoto.ai` / `https://api.timoto.ai`) plus WebSocket `:8443` with Cognito token (`apps/src/services/realtimeOperatorReview.ts`). The app **never** calls internal HMAC or gRPC. Dealer URL `https://dealer.timoto.ai` is for Zalo dealer OAuth, not seller evaluate.

## Backend ↔ others

- AI: gRPC `EvaluateByBikeId`
- Internal: HMAC GET operator-offer; `pg_notify` operator\_channel; webhook new-submission
- Dealer: checkout S2S, `bike-unavailable`; inbound paid-hook \+ buyer-found HMAC

## Gaps vs app code

`marketplaceBuyService.ts` calls `/marketplace/purchase-orders/` and `/marketplace/payments/` — **no matching `urls.py`**. Treat as WIP. Do not document as live. Contract tests in `test_purchase_orders_api.py` are explicitly skipped.

## Tests & Coverage (292 Unit Tests, 100% PASS)

The Django backend test suite uses isolated in-memory SQLite (`config.settings_test`).

- **Total Unit Tests**: 292 targeted tests across 30 test files (297 total DB discoverable tests).
- **`apps/users`** (55 tests): OTP login, profile `GET/PUT/PATCH /auth/me/`, native Zalo PKCE & proxy fallback, Apple sign-in, account soft-delete & reactivation, FCM push tokens.
- **`apps/bikes`** (141 tests): Pickup schedule creation & patch, marketplace listings & filters, sale history processing/completed tabs, operator review cancellation, realtime valuation rejection.
- **`apps/evaluation`** (49 tests): HMAC SHA-256 signatures, AI evaluation pipeline (`output_jsons`), TIPP dual-pricing, buyback resolution, seller listing status.
- **`apps/feedback`, `apps/ocr`, `apps/options`** (33 tests): User feedback, cavet OCR parsing, FMP price range estimation.

## Do not

- Do not put `OPERATOR_OFFER_INTERNAL_HMAC_SECRET` in the app.
- Do not call `/api/v1/evaluation/full/` from Apps — production is `/bikes/{id}/evaluate/`.
