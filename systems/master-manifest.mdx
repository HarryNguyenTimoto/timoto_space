# Master 6-Repository Architecture Knowledge Base

This documentation represents an exhaustive, zero-handwaving line-by-line reverse-engineering of the entire TiMoto platform across **6 codebases**:

1. **`timoto-mobile`**: Rider & Seller React Native Application (`Apps/src/`) & Backend (`backend/apps/bikes/`).
2. **`timoto-internal-app`**: Operations Web & Mobile Application (`backend/bikes/`, `backend/ops_auth/`).
3. **`timoto-dealer-portal`**: B2B Dealer Django Backend Engine (`backend/catalog/`, `backend/orders/`, `backend/payments/`).
4. **`timoto_dealer_portal_v2`**: Modern B2B Dealer React SPA (`frontend/src/`).
5. **`TiMoto-AI-Web`**: AWS Lambda Serverless Waitlist & Public AI Marketing (`infrastructure/waitlist/`, `frontend/src/`).
6. **`chototcaodulieu`**: Data Ingestion Engine & Scraping Pipeline (`chotot.py`, `lambda_handler.py`, `refresh_handler.py`).
